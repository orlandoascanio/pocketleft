Open your Pocket

  1. On a device that's already connected, open Settings. (On a Mac: Pocket → Settings → Sync.)
  2. Choose Pair a new device. A 6-digit code appears.
  3. Type that code here.

Each code works once and expires after 10 minutes. This device then stays signed in.
